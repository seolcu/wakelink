    깨우기 버튼 한 번

    상대 폰에 큰 알람이 울리고, 실제로 울렸는지와 상대가 알람을 껐는지가 내 화면에 떠요.

내 소리, 내 사진으로 깨우기

똑같은 알람 소리는 지겨우니까. 무엇을 울리고 보여 줄지는 보내는 사람이, 허용 범위는 받는 사람이 정해요.

기본 벨소리 6가지

클래식 비프, 디지털, 차임, 점점 높아지는 음, 종소리, 마림바 중에서 미리 듣고 선택.

내 목소리, 내 음악

"일어나!"를 15초까지 녹음하거나, 폰에 있는 오디오 파일을 그대로 보내기.

알람 화면에 사진과 한마디

사진이나 움직이는 GIF, 짧은 메시지를 상대 알람 화면에. 사진은 카메라로 바로 찍어 보낼 수도 있어요.

무음 모드여도 울리는 이유

폰을 무음으로 해도 시계 앱 알람은 울리죠. 무음 모드는 벨소리와 알림 소리만 끄고 알람 소리는 그대로 두기 때문이에요.

WakeLink도 같은 알람 채널을 써서, 특별한 권한 없이 무음·진동 모드에서도 울려요.

폰의 알람 볼륨이 작아도, 울리는 동안만 받는 사람이 정한 볼륨으로 바꿨다가 끝나면 되돌려 놓아요.

방해 금지의 '완전 무음'은 알람까지 막아요. 설정에서 켜 두면 이것도 울리는 동안만 풀었다가 다시 돌려놓아요.

  • 소리 모드울림
  • 진동 모드울림
  • 무음 모드울림
  • 방해 금지 (알람 허용)울림
  • 방해 금지 '완전 무음'설정에서 켜면 울림

아무나 깨울 수 없게

누군가를 깨우는 앱이라서, 동의와 통제권을 가장 먼저 생각했어요.

서로 동의해야 연결

초대 코드를 받은 사람이 직접 입력해야만 연결. 몰래 추가하는 방법은 없어요.

방향별로 따로 허락

"나는 깨울 수 있지만 상대는 나를 못 깨우게"처럼 각자 따로 설정.

언제든 끄거나 끊기

앱 전체 끄기, 특정 사람만 막기, 연결 끊기 모두 언제든 가능.

상태는 늘 첫 화면에

깨우기를 받는 중인지 첫 화면 맨 위에 항상 표시. 거기서 바로 끌 수도 있어요.

장난 방지

같은 사람에게는 30초에 한 번, 24시간에 20번까지만.

종단간 암호화

보낸 사람 이름, 메시지, 녹음, 파일, 사진은 받는 사람 폰만 열 수 있게 암호화. 서버는 암호문만 전달하고, 계정을 지우면 모두 삭제돼요.

자주 묻는 질문

아이폰에서도 쓸 수 있나요?

아직은 Android만 지원해요. 깨우는 사람과 깨워지는 사람 모두 Android 폰이 있어야 해요.

앱은 어떤 언어를 지원하나요?

한국어와 영어예요. 폰 언어를 따라가고, Android 13 이상이면 시스템 설정에서 WakeLink만 따로 언어를 고를 수도 있어요.

플레이 스토어에 없는데 설치해도 괜찮나요?

위 버튼으로 받는 APK는 GitHub에 공개된 소스로 빌드되고, 늘 같은 키로 서명돼요. 처음 한 번만 브라우저나 파일 앱에 "출처를 알 수 없는 앱 설치"를 허용하면 돼요.

업데이트는 어떻게 하나요?

새 버전이 나오면 알림이 오고, 누르면 바로 설치 화면까지 열려요. 설정 → 앱 업데이트에서 직접 확인도 가능.

배터리 절약 때문에 안 울리면 어떡하죠?

앱을 처음 켜면 알림, 잠금 화면 전체 화면 알람, 배터리 최적화 제외를 차례로 안내하고, 나중에 꺼지면 다시 알려 줘요. 삼성 폰은 '절전 앱' 목록에서도 빼 주세요.

보낸 사진과 녹음은 누가 볼 수 있나요?

깨우기를 받는 사람만요. 올리기 전에 내 폰에서 암호화되고, 그 열쇠는 받는 사람 폰만 열 수 있게 봉인해서 보내요. 서버도, 푸시를 전달하는 Google도 내용을 볼 수 없고, 계정을 지우면 서버에서도 지워져요.

폰을 재부팅하고 잠금을 아직 안 풀었어도 울리나요?

네. 새벽에 자동 재시작된 폰도 울려요. 다만 잠금을 풀기 전에는 암호화된 내용을 열 수 없어서, 보낸 사람 이름과 고른 소리·사진·메시지 대신 내 기본 소리로 울려요.

깨우기를 보냈는데 상대 폰이 꺼져 있으면요?

보낸 쪽 화면에 "울림 미확인"으로 표시돼요. 상대 폰에서 소리가 실제로 나야만 "울림 확인됨"으로 바뀌고, 상대가 알람을 직접 끄면 그 시각도 떠요.

제 서버에서 직접 운영할 수 있나요?

네. 서버와 앱 모두 MIT 라이선스 오픈소스예요. 다만 푸시 알림 구조상 서버만 바꿔서는 안 되고, 자신의 Firebase 프로젝트로 앱도 직접 빌드해야 해요. 호스팅 안내를 참고하세요.
